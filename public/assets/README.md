# Biblioteca de assets

A pasta `models/` contém os GLBs usados diretamente pelo jogo. As demais pastas existem para manter a expansão organizada e evitar assets espalhados pelo código.

- `models/`: personagens, criaturas, alimento, props e elementos interativos em GLB.
- `textures/`: texturas leves e materiais futuros.
- `animations/`: clips de animação exportados quando deixarem de ser procedurais.
- `icons/`: ícones específicos do jogo.
- `ui/`: imagens de interface que não sejam ícones genéricos.

Assets prioritários devem ter silhueta reconhecível, escala consistente e custo visual proporcional à importância no jogo.
